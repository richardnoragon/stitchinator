# FAQ

**Is this open source?** The repository is public, but no open-source license has been selected. See [license status](../LICENSE.md).

**Is it ready for a release?** It is an internal prototype with synthetic technical checks. Real craft acceptance, amigurumi yarn calibration and cross-platform host verification remain open.

**Does it need internet?** Initial builds/downloads do. Normal use, storage and OCR are local and offline.

**Where is my data?** In the configured data directory/volume and separate host backup folder. Individual project downloads do not contain the entire shared inventory or picture library; use collection backups for full recovery.

**Can it read any crochet PDF or finished-object photo?** OCR proposes rounds from written instructions in supported notation. Unknown syntax is flagged. Symbol-only charts and finished-object photos require manual interpretation; they do not determine a unique pattern.

**Are the 3D models physically accurate?** They illustrate geometry and procedural stitch loops. They do not validate drape, stuffing, arbitrary stitch topology or printability. Missing gauge is labeled uncalibrated.

**How do I make modified library patterns?** Edit a separate copy and save under a unique new name. Original shared entries are read-only.

**What should be worked on next?** See [roadmap](ROADMAP.md) and [project tracking](PROJECTS.md).
